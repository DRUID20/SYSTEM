## 1. Purpose

To define the processes, formats, and timelines for producing management reports that enable data-driven decision-making by the CFO, CEO, and Board of Directors of Awdeer Investments Limited. This SOP covers monthly management accounts, cash flow reporting, profitability by business line, and budget vs actual analysis.

---

## 2. Scope

Covers all periodic management reporting across the consolidated group and each business line (Energy, Real Estate, Logistics, Retail, Services). Excludes statutory financial statements (prepared separately for audit) and tax filings (covered under FIN-TAX-001).

## 6. Monthly Management Accounts Pack

### 6.1 Contents

The Management Accounts Pack (FIN-TPL-011) includes the following sections:

| Section | Content |
|---------|---------|
| 1. Executive Summary | One-page CFO commentary highlighting key results, risks, and actions |
| 2. Consolidated Income Statement | Revenue, COGS, gross profit, OPEX, EBITDA, net profit (current month + YTD) |
| 3. Income Statement by Business Line | Same structure for each BL: Energy, Real Estate, Logistics, Retail, Services |
| 4. Budget vs Actual | Line-by-line comparison with variance (amount and %) and explanations for material variances |
| 5. Balance Sheet | Full balance sheet with prior period comparative |
| 6. Cash Flow Statement | Direct method; operating, investing, financing activities |
| 7. Key Financial Metrics | See Section 8 for KPIs |
| 8. AR Aging Summary | By aging bucket and business line |
| 9. AP Aging Summary | By aging bucket and business line |
| 10. Headcount & Staff Cost Summary | By business line and department |
| 11. CAPEX Report | Budget vs actual, CWIP status, asset additions |
| 12. Tax Summary | Taxes paid, filed, and outstanding |
| 13. 13-Week Cash Forecast | Summary from Treasury |
| 14. Action Items | Open items from prior month and new items |

| Step | Action | Owner | Timeline |

### 7.2 Cash Conversion Cycle

Calculated monthly:

```
Cash Conversion Cycle = DSO + DIO - DPO

Where:
DSO = Days Sales Outstanding (AR / Revenue x 365)
DIO = Days Inventory Outstanding (Inventory / COGS x 365)
DPO = Days Payable Outstanding (AP / COGS x 365)
```

Target: Cash conversion cycle < 45 days.

### 9.2 Variance Classification

| Variance Type | Threshold | Action Required |
|--------------|-----------|-----------------|
| Favorable (revenue above budget) | Any | Note and explain |
| Favorable (expense below budget) | Any | Note and explain |
| Unfavorable < 5% | < 5% | Monitor |
| Unfavorable 5%–10% | 5%–10% | Explain in commentary |
| Unfavorable > 10% OR > UGX 5,000,000 | > 10% or > UGX 5M | Written explanation + corrective action plan |
| Unfavorable > 20% | > 20% | Escalation to CFO with root cause analysis |

### 9.3 Variance Explanation Template

For each material variance:

```

Root Cause: [Brief explanation]
Corrective Action: [What will be done]
Owner: [Person responsible]
Timeline: [When it will be resolved]
```

## 10. Key Financial Metrics and KPIs

### 10.1 Monthly KPI Dashboard

| Category | KPI | Formula | Target |
|----------|-----|---------|--------|
| **Profitability** | Gross Margin | Gross Profit / Revenue | > 35% |
| | EBITDA Margin | EBITDA / Revenue | > 15% |
| | Net Profit Margin | Net Profit / Revenue | > 8% |
| | Return on Equity (ROE) | Net Profit / Equity (annualised) | > 20% |
| **Liquidity** | Current Ratio | Current Assets / Current Liabilities | > 1.5 |
| | Quick Ratio | (Current Assets - Inventory) / Current Liabilities | > 1.0 |
| | Cash Ratio | Cash / Current Liabilities | > 0.3 |
| **Efficiency** | DSO | AR / Revenue x 365 | < 35 days |
| | DPO | AP / COGS x 365 | 30–45 days |
| | DIO | Inventory / COGS x 365 | < 30 days |
| | Cash Conversion Cycle | DSO + DIO - DPO | < 45 days |
| **Leverage** | Debt-to-Equity | Total Debt / Total Equity | < 1.0 |
| | Interest Coverage | EBIT / Interest Expense | > 3.0x |
| **Growth** | Revenue Growth (MoM) | (Current - Prior) / Prior | Per budget |
| | Revenue Growth (YoY) | (Current - Prior Year) / Prior Year | Per budget |
| **Cost** | Staff Cost as % of Revenue | Total Staff Cost / Revenue | < 30% |
| | OPEX as % of Revenue | Total OPEX / Revenue | < 25% |

## 14. Lean Version

For early-stage operations:

- Simplified P&L and balance sheet (no business line breakdown)
- Budget vs actual at summary level only
- Cash position report instead of full cash flow statement
- 5 key KPIs only (revenue, gross margin, cash balance, DSO, burn rate)
- Monthly one-page CFO report to CEO
- No formal management meeting; CFO briefing to CEO

---

## 15. Controlled Version

Full process as described above, plus:

- Automated reporting from ERP / BI tool (Power BI / Google Data Studio)
- Real-time financial dashboard accessible by CEO and CFO
- Full business line profitability with allocated costs
- Rolling 12-month forecast updated monthly
- Scenario analysis (best case, base case, worst case)
- Quarterly investor reporting pack (if external investors)
- Annual strategic planning support (5-year financial model)
- Benchmark analysis against industry peers
