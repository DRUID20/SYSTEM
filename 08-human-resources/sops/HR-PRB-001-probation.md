## 1. Purpose

This SOP defines the process for managing employee probation periods, conducting probation assessments, and making confirmation, extension, or termination decisions. It ensures fair, documented, and timely evaluation of new employees.

## 2. Scope

This SOP applies to all new employees serving a probationary period. The standard probation period is **3 months (90 calendar days)** from the date of joining. This SOP also covers probation extensions (maximum 3 additional months).

## 5. Step-by-Step Workflow

### Phase 1: Goal Setting (Week 1–2)

| Step | Action | Responsible | Timeline | Notes |
|------|--------|------------|----------|-------|
| 1.1 | Line manager sets 3–5 measurable goals for the 90-day probation period | Line Manager | Day 7–10 | Aligned with job description; SMART goals |
| 1.2 | Goals discussed and agreed with employee | Line Manager + Employee | Day 10–14 | Employee signs agreement |
| 1.3 | Copy of goals submitted to HR | Line Manager | Day 14 | Filed in personnel folder |
| 1.4 | HR Officer sets calendar reminders for check-ins and review | HR Officer | Day 14 | Month 1, Month 2, Month 3 |

### Phase 2: Monthly Check-Ins

#### Month 1 Check-In (Day 28–30)

| Step | Action | Responsible | Timeline | Notes |
|------|--------|------------|----------|-------|
| 2.1 | Line manager conducts informal check-in meeting | Line Manager | Day 28–30 | 30-minute meeting |
| 2.2 | Discuss progress against goals, any concerns, support needed | Line Manager + Employee | Same meeting | Two-way conversation |
| 2.3 | Document key points and any action items | Line Manager | Same day | Brief notes (email or form) |
| 2.4 | Share notes with HR | Line Manager | Within 2 days | Filed in personnel folder |
| 2.5 | If significant concerns: escalate to HR Manager early | Line Manager | As needed | Do not wait until Month 3 |

#### Month 2 Check-In (Day 55–60)

| Step | Action | Responsible | Timeline | Notes |
|------|--------|------------|----------|-------|
| 2.6 | Line manager conducts second check-in | Line Manager | Day 55–60 | 30-minute meeting |
| 2.7 | Review progress, feedback, updated expectations | Line Manager + Employee | Same meeting | Address any performance gaps |
| 2.8 | Document and share with HR | Line Manager | Within 2 days | Provides early warning for review |
| 2.9 | If likely non-confirmation: HR Manager informed; counselling initiated | Line Manager + HR Manager | Day 60 | Employee given clear improvement targets |

### Phase 3: Formal Probation Review (Day 80–90)

| Step | Action | Responsible | Timeline | Notes |
|------|--------|------------|----------|-------|
| 3.1 | HR Officer sends probation review reminder to line manager | HR Officer | Day 75 | Include review form and instructions |
| 3.2 | Line manager prepares Probation Review Form | Line Manager | Day 75–80 | Assess each goal and criterion |
| 3.3 | Line manager gathers input (attendance, training completion, colleague feedback for Controlled) | Line Manager + HR Officer | Day 75–80 | Evidence-based assessment |
| 3.4 | Conduct formal probation review meeting | Line Manager + Employee (HR Manager present for G3+ or concerns) | Day 85–88 | 45–60 minute meeting |
| 3.5 | Discuss assessment results with employee | Line Manager | During meeting | Employee given opportunity to respond |
| 3.6 | Employee signs review form (may add comments) | Employee | During meeting | Employee signature confirms discussion, not agreement |
| 3.7 | Line manager records recommendation: Confirm / Extend / Terminate | Line Manager | Same day | With justification |
| 3.8 | Submit completed form to HR Manager for review | Line Manager | Day 88 | — |

### Phase 4: Decision and Action

#### If Confirmed:

| Step | Action | Responsible | Timeline | Notes |
|------|--------|------------|----------|-------|
| 4.1 | HR Manager reviews and approves confirmation (or escalates per approval matrix) | HR Manager | Day 88–89 | G3+: Department Head and/or MD approval |
| 4.2 | HR Officer prepares confirmation letter | HR Officer | Day 89 | Include confirmed terms, benefits changes (if any) |
| 4.3 | HR Manager signs confirmation letter | HR Manager | Day 89–90 | — |
| 4.4 | Line manager presents confirmation letter to employee | Line Manager | Day 90 | Congratulatory meeting |
| 4.5 | Update employee status in HRIS / payroll | HR Officer | Day 90 | Status: "Confirmed" |
| 4.6 | File all probation documents in personnel folder | HR Officer | Day 90 | Review form, confirmation letter |

#### If Extended:

| Step | Action | Responsible | Timeline | Notes |
|------|--------|------------|----------|-------|
| 4.7 | HR Manager reviews extension recommendation with MD | HR Manager | Day 88–89 | MD must approve all extensions |
| 4.8 | Prepare Performance Improvement Plan (PIP) with clear targets | Line Manager + HR Manager | Day 89 | Specific, measurable, time-bound targets |
| 4.9 | HR Officer prepares extension letter (maximum 3 additional months) | HR Officer | Day 89 | State extension period, targets, consequences |
| 4.10 | Meet employee to discuss extension, PIP, and expectations | Line Manager + HR Manager | Day 90 | Employee signs extension letter and PIP |
| 4.11 | Set bi-weekly check-in schedule during extension | Line Manager + HR Officer | Day 90 | Calendar reminders set |
| 4.12 | Conduct final review at end of extension period | Line Manager + HR Manager | End of extension | Confirm or terminate — no further extension |

#### If Terminated:

| Step | Action | Responsible | Timeline | Notes |
|------|--------|------------|----------|-------|
| 4.13 | HR Manager reviews termination recommendation with MD | HR Manager | Day 88–89 | Controlled: Legal review |
| 4.14 | HR Officer prepares termination notice (2 weeks notice during probation) | HR Officer | Day 89 | Per Employment Act provisions |
| 4.15 | Meet employee to communicate decision | HR Manager + Line Manager | Day 90 | Private, respectful meeting |
| 4.16 | Issue termination notice to employee | HR Manager | Same day | Written notice with last working day |
| 4.17 | Initiate exit process (HR-TRM-001) | HR Officer | Same day | Asset recovery, access revocation |
| 4.18 | Process final pay (salary + accrued leave) | HR Officer + Finance | Within 7 working days of last day | Per Employment Act |
| 4.19 | File all documentation | HR Officer | Within 14 days | For compliance and audit trail |

## 6. Controls and Approvals

| Control | Description | Lean | Controlled |
|---------|-------------|------|-----------|
| Goal documentation | 90-day goals documented and signed | Yes | Yes (filed in HRIS) |
| Monthly check-ins | Documented conversations at Month 1 and Month 2 | Brief notes | Structured form |
| Early warning | Concerns escalated to HR before formal review | Verbal | Written with HR Manager involvement |
| Formal review | Structured assessment using Probation Review Form | Line Manager + HR | Line Manager + HR Manager + Dept Head |
| Multi-level approval | Confirmation/extension/termination approved per matrix | HR Manager + MD (termination/extension) | Full approval chain |
| Legal review | Termination reviewed for legal compliance | HR Manager checks | Legal counsel review |
| Employee voice | Employee signs review form and may add comments | Yes | Yes |
| Documentation | Complete file maintained | Essential docs | Full trail including check-in notes |
| Calendar management | Automated reminders for reviews | Manual calendar | HRIS automated reminders |

## 9. Lean vs Controlled Version Summary

| Aspect | Lean | Controlled |
|--------|------|-----------|
| Goal setting | Verbal agreement, brief written summary | Formal goals form signed by both parties |
| Monthly check-ins | Informal conversation; brief email notes | Structured form; filed in HRIS |
| Probation review panel | Line Manager + HR Manager | Line Manager + HR Manager + Department Head |
| Assessment evidence | Manager observation + attendance | 360 input + attendance + training + colleague feedback |
| Approval chain (confirm) | HR Manager (G1–G2); MD (G3+) | Line Manager → HR Manager → Dept Head → MD (G3+) |
| Legal review (termination) | HR Manager reviews | Legal counsel reviews |
| Documentation | Paper-based | HRIS with automated workflows |
| Calendar management | Manual reminders | Automated HRIS reminders |
| Extension PIP | Line Manager prepares | HR Manager + Line Manager co-prepare; formal template |
