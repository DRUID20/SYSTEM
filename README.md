# Awdeer Investments Limited — Business Operating System

## Playbook Structure

| # | Section | Description |
|---|---------|-------------|
| 00 | Executive Summary | High-level overview of the operating system |
| 01 | Company Operating Model | Org structure, departments, high-level flows |
| 02 | Governance & Administration | Board governance, DoA, policies, risk |
| 03 | Strategy, Planning & Performance | OKRs, QBRs, project management |
| 04 | Finance | Full CFO-level finance engine |
| 05 | Procurement & Vendor Management | PR-to-PO, supplier evaluation |
| 06 | Inventory, Stores & Logistics | Stock management, fleet, warehousing |
| 07 | Sales, Marketing & Customer Ops | CRM, pipeline, customer management |
| 08 | Human Resources | End-to-end HR system |
| 09 | Legal, Compliance & Risk | Contracts, compliance, AML, data protection |
| 10 | IT & Digital Operations | Tools stack, access control, cyber hygiene |
| 11 | Internal Audit | Audit charter, programs, CAPA |
| 12 | ERP Blueprint | Modules, roles, workflows, master data |
| 13 | Implementation Roadmap | 30/60/90-day and 6/12-month plan |
| 14 | Templates Pack | All templates indexed and ready to use |
| 15 | Optional Extensions | Branch pack, director pack, brand system |

## Document Naming Convention

All documents follow the pattern: `[DEPT]-[AREA]-[SEQ] Title`

| Prefix | Department |
|--------|-----------|
| GOV | Governance & Administration |
| STR | Strategy & Planning |
| FIN | Finance |
| PRO | Procurement |
| INV | Inventory & Stores |
| SAL | Sales & Marketing |
| HR | Human Resources |
| LEG | Legal & Compliance |
| IT | IT & Digital |
| AUD | Internal Audit |

Examples:
- `FIN-AP-001` Payment Voucher
- `HR-REC-001` Job Description Template
- `PRO-PUR-001` Purchase Requisition

## Versions

Each process is documented in two versions:
- **Lean** — for small teams (< 15 people)
- **Controlled** — for mid-size teams (15–100+ people)

## Implementation

This system is designed to be implemented in Odoo / SAP / Zoho / Google Workspace.
See `12-erp-blueprint/` for detailed module mapping.
