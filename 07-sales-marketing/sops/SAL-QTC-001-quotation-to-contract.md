## 1. Purpose

This SOP defines the standard process for preparing, approving, issuing, and converting customer quotations into binding contracts or purchase orders. It ensures pricing accuracy, proper authorization of discounts, consistency in customer-facing documents, and a clear audit trail from proposal to signed agreement.

## 5. Step-by-Step Workflow

### Step 1: Receive Quotation Request

| Detail | Description |
|--------|------------|
| **Action** | Customer requests a formal quotation (verbally, by email, or via RFQ document) |
| **Who** | Sales Executive |
| **How** | Log the request in CRM; update pipeline stage to Proposal |
| **SLA** | Log same day as request received |
| **Notes** | Gather all specifications: quantities, delivery requirements, timeline, special terms |

### Step 2: Determine Pricing

| Detail | Description |
|--------|------------|
| **Action** | Determine the applicable pricing for the customer and products/services requested |
| **Who** | Sales Executive, with Sales Manager oversight |
| **How** | Check standard price list. If standard pricing applies, proceed to Step 3. If discount or custom pricing is needed, proceed to Step 2b |
| **Reference** | Customer segmentation and pricing tiers (see main document Section 3) |

### Step 2b: Request Discount / Custom Pricing Approval

| Detail | Description |
|--------|------------|
| **Action** | Complete the Pricing Approval Form (SAL-TPL-003) and submit for approval |
| **Who** | Sales Executive (prepares); Sales Manager / MD (approves) |
| **How** | Fill in: customer details, standard price, proposed price, discount %, justification, margin impact |
| **Approval Thresholds** | 1–5%: Sales Manager (Controlled) / MD (Lean); 6–10%: Sales Manager + MD; 11–15%: MD; >15%: Not standard — requires Board/MD special resolution |
| **SLA** | Approval within 2 business days |
| **Control** | Sales Executive cannot approve own discount requests |

### Step 3: Prepare Quotation Document

| Detail | Description |
|--------|------------|
| **Action** | Prepare the formal quotation using the Quotation Template (SAL-TPL-002) |
| **Who** | Sales Executive |
| **How** | Complete all sections: customer details, line items with descriptions, quantities, unit prices (UGX), VAT (18% where applicable), total, payment terms, delivery terms, validity period, terms and conditions |
| **Quotation Number** | Sequential format: `AWD-QTN-YYYY-NNNN` (e.g., AWD-QTN-2026-0001) |
| **SLA** | Within 1 business day of pricing confirmation |

### Step 4: Internal Review

| Detail | Description |
|--------|------------|
| **Action** | Sales Manager reviews the quotation for accuracy before it is sent to the customer |
| **Who** | Sales Manager |
| **Review Checklist** | Customer name and details correct; Line items match customer request; Pricing matches approved rates (and Pricing Approval Form if applicable); VAT correctly applied (18%); Payment and delivery terms are per policy; Quotation validity period stated; Terms and conditions included; Quotation number assigned |
| **SLA** | Within 1 business day |
| **Lean version** | MD reviews quotations > UGX 5,000,000; Sales Lead self-reviews others |

### Step 5: Approve Quotation

| Detail | Description |
|--------|------------|
| **Action** | Approve the quotation for release to customer |
| **Who** | Sales Manager (standard); MD (above threshold or discounted) |
| **How** | Sign-off on quotation (physical signature, email approval, or ERP approval) |
| **Thresholds (Controlled)** | Up to UGX 20,000,000: Sales Manager; UGX 20,000,001–100,000,000: MD; Above UGX 100,000,000: MD + Finance review |
| **Thresholds (Lean)** | Up to UGX 5,000,000: Sales Lead; Above UGX 5,000,000: MD |
| **SLA** | Same day after review completion |

### Step 6: Send Quotation to Customer

| Detail | Description |
|--------|------------|
| **Action** | Send the approved quotation to the customer |
| **Who** | Sales Executive |
| **How** | Email (PDF attachment) with professional cover email; or hand-deliver with receipt acknowledgement |
| **SLA** | Same day as approval |
| **Notes** | Save sent quotation in CRM/document system; set follow-up reminder per validity period |

### Step 7: Customer Follow-Up

| Detail | Description |
|--------|------------|
| **Action** | Follow up with the customer to confirm receipt and answer questions |
| **Who** | Sales Executive |
| **How** | Phone call or email 2–3 business days after sending |
| **SLA** | First follow-up within 3 business days of sending |
| **Cadence** | Follow up at: Day 3, Day 7, Day 12 (before 14-day expiry) or Day 7, Day 14, Day 21, Day 28 (before 30-day expiry) |

### Step 8: Handle Negotiation / Revision

| Detail | Description |
|--------|------------|
| **Action** | If the customer requests changes to pricing, terms, or scope, negotiate and prepare a revised quotation |
| **Who** | Sales Executive (negotiates); Sales Manager (approves revisions) |
| **How** | Update CRM stage to Negotiation; document customer feedback; if revised pricing requires new discount, repeat Step 2b; prepare revised quotation (mark as Revision: e.g., `AWD-QTN-2026-0001-R1`) |
| **SLA** | Revised quotation within 2 business days of customer feedback |
| **Control** | All revised quotations require Sales Manager approval |

### Step 9: Receive Customer Acceptance

| Detail | Description |
|--------|------------|
| **Action** | Customer accepts the quotation by signing the contract, issuing a PO, or providing written acceptance |
| **Who** | Sales Executive receives; Sales Manager validates |
| **How** | Obtain signed contract (using SAL-TPL-004 as outline) or customer's PO; verify that accepted terms match the quotation |
| **SLA** | Validate acceptance same day as received |
| **Notes** | If the customer's PO terms differ from quotation, flag to Sales Manager for resolution before proceeding |

### Step 10: Contract Execution (for Formal Contracts)

| Detail | Description |
|--------|------------|
| **Action** | For deals requiring a formal contract (typically > UGX 50,000,000 or long-term engagements), prepare and execute the contract |
| **Who** | Sales Manager (coordinates); Legal (reviews if > UGX 100,000,000); MD (signs) |
| **How** | Use Sales Contract Outline (SAL-TPL-004) as the basis; Legal reviews terms for high-value contracts; both parties sign; file original and provide copy to customer |
| **SLA** | Contract execution within 5 business days of customer acceptance |

### Step 11: Handoff to Order Management

| Detail | Description |
|--------|------------|
| **Action** | Hand off the closed deal to operations for fulfilment |
| **Who** | Sales Executive |
| **How** | Update CRM stage to Won; enter order in system per SAL-ORD-001; provide order pack: signed quotation/contract, customer requirements, delivery details, special instructions |
| **SLA** | Same day as contract/PO confirmed |

### Step 12: Close as Lost (if applicable)

| Detail | Description |
|--------|------------|
| **Action** | If the customer declines or does not respond within the follow-up window, close as Lost |
| **Who** | Sales Executive |
| **How** | Update CRM stage to Lost; record loss reason; notify Sales Manager |
| **SLA** | Close as Lost after 3 follow-up attempts with no response, or immediately upon customer decline |
| **Notes** | Sales Manager reviews lost deals monthly for patterns and improvement opportunities |

## 6. Controls & Approvals

| Control Point | Control Description | Owner |
|--------------|-------------------|-------|
| Sequential quotation numbering | Prevents gaps and ensures traceability; no quotation sent without a number | CRM system / Sales Manager |
| Pricing approval before quotation | Discounted pricing requires written approval before quotation is prepared | Sales Manager / MD |
| Internal review before sending | Every quotation is reviewed for accuracy before customer delivery | Sales Manager |
| Approval thresholds (value-based) | Higher-value quotations require higher-level approval per DoA | Per DoA matrix |
| Quotation validity enforcement | All quotations have a stated validity period; expired quotations must be re-issued | Sales Executive / CRM |
| Segregation of duties | Person preparing the quotation is not the same as the person approving it (for discounted or high-value) | Sales Manager / MD |
| Margin floor check | Finance validates that proposed pricing meets minimum gross margin before approval (for custom pricing) | Finance Manager |
| Contract-to-quotation match | Signed contract/PO terms must match the approved quotation | Sales Manager validates |
| Document retention | All quotations (sent and revised), approval forms, and contracts are filed in CRM/document system | Sales Executive |
| Audit trail | CRM records the full history: quotation versions, approvals, communications | CRM system |

## 8. KPIs

| KPI | Definition | Target | Measurement Frequency |
|-----|-----------|--------|----------------------|
| Quotation Response Time | Average days from customer request to quotation sent | < 2 business days | Monthly |
| Quotation Win Rate | Quotations converted to orders / Total quotations issued | > 40% | Monthly |
| Average Deal Size | Total value of won quotations / Number of won quotations | Increasing trend | Monthly |
| Discount Frequency | % of quotations issued with discount vs list price | < 30% | Monthly |
| Average Discount Given | Average discount % across all discounted quotations | < 7% | Monthly |
| Quotation Revision Rate | % of quotations requiring revision after initial send | < 20% | Monthly |
| Quotation Approval Cycle Time | Average days from quotation preparation to approval | < 1 business day | Monthly |
| Contract Execution Time | Average days from customer acceptance to signed contract | < 5 business days | Monthly |
| Quotation Expiry Rate | % of quotations that expire without customer response | < 30% | Monthly |
| Gross Margin on Won Deals | Average gross margin % on deals closed | > [business line target] | Monthly |

## 9. Lean Version — Summary

| Element | Lean Approach |
|---------|--------------|
| Quotation preparation | Sales Lead prepares using SAL-TPL-002 in Word/Google Docs |
| Pricing | Standard price list; Sales Lead proposes; MD approves discounts |
| Approval | MD reviews and approves all quotations > UGX 5,000,000 via email |
| Quotation numbering | Manual sequential numbering in spreadsheet tracker |
| Sending | Email PDF to customer; save copy in shared folder |
| Negotiation | Sales Lead handles; escalates to MD for significant changes |
| Contract | Simple acceptance letter or PO for most deals; formal contract for > UGX 20,000,000 |
| Filing | Shared Google Drive / OneDrive folder organized by customer |
| Follow-up | Calendar reminders set by Sales Lead |
| Reporting | Monthly count of quotations sent, won, lost, value |

## 10. Controlled Version — Summary

| Element | Controlled Approach |
|---------|-------------------|
| Quotation preparation | CRM/ERP quotation module with templates and auto-numbering |
| Pricing | Price list in ERP; discount rules configured; Pricing Approval Form for exceptions |
| Approval | ERP approval workflow: Sales Manager up to UGX 20M, MD above; Finance for > UGX 50M |
| Quotation numbering | Auto-generated by ERP: `AWD-QTN-YYYY-NNNN` |
| Sending | Emailed directly from ERP with PDF attachment and tracking |
| Negotiation | All revisions tracked in CRM with version history |
| Contract | Formal contract per SAL-TPL-004 for > UGX 50M; Legal review for > UGX 100M |
| Filing | All documents stored in CRM/ERP document management |
| Follow-up | Automated CRM reminders and escalation for pending quotations |
| Reporting | Automated dashboards: win rate, response time, discount analysis, pipeline value |
| Analytics | Win/loss analysis by customer segment, business line, sales person, loss reason |
