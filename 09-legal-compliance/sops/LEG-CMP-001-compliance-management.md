## 1. Purpose

To establish the standard operating procedure for maintaining, monitoring, and reporting on all legal and regulatory compliance obligations of Awdeer Investments Limited, ensuring that all filings, renewals, and regulatory requirements are identified, tracked, and fulfilled on time.

---

## 2. Scope

This SOP covers all compliance obligations arising from:

- Company registration and corporate governance (URSB, Companies Act 2012)
- Tax obligations (URA — Income Tax Act, VAT Act, PAYE, WHT)
- Employment obligations (NSSF, Employment Act 2006)
- Business licensing (KCCA/local government trading licences)
- Sector-specific permits and licences (Energy, Transport, Real Estate)
- Insurance requirements (statutory and commercial)
- Data protection (DPPA 2019, PDPO registration)
- Environmental compliance (NEMA, where applicable)
- Any other regulatory obligation applicable to the company's operations

## 5. Step-by-Step Workflow

### Step 1: Identify Compliance Obligations

| Detail | Description |
|--------|-------------|
| **Action** | Identify all legal and regulatory obligations applicable to Awdeer Investments Limited |
| **Who** | Legal/Compliance Officer |
| **How** | Review all applicable legislation (see Section 3 of main document). Consult sector regulators. Review business activities for each business line. Engage external counsel for specialist areas |
| **Frequency** | Comprehensive review annually; ad-hoc when new laws enacted or business lines added |
| **Output** | Complete list of obligations with: regulation source, obligation description, deadline, responsible person, evidence required |

### Step 2: Build and Maintain Compliance Register

| Detail | Description |
|--------|-------------|
| **Action** | Record all identified obligations in the Compliance Register |
| **Who** | Legal/Compliance Officer |
| **Format** | Register must contain: obligation ID, regulation/law, specific requirement, frequency, deadline, responsible person, evidence required, status, last completed date, next due date, comments |
| **Tool** | Spreadsheet (Lean) or ERP compliance module (Controlled) |
| **Update** | Register updated whenever new obligations identified, deadlines change, or status changes |

### Step 3: Set Up Monitoring and Alerts

| Detail | Description |
|--------|-------------|
| **Action** | Configure alerts for all compliance deadlines |
| **Who** | Legal/Compliance Officer |
| **Alert Schedule** | 90 days before due (planning alert), 60 days before due (preparation alert), 30 days before due (action alert), 7 days before due (urgent alert), on due date (deadline alert) |
| **Method** | Calendar entries, ERP alerts, email reminders |
| **Escalation** | If not actioned by 14 days before deadline, escalate to MD |

### Step 4: Execute Compliance Activities

| Detail | Description |
|--------|-------------|
| **Action** | Complete each compliance obligation by its deadline |
| **Who** | Responsible person as assigned in the register |
| **Tax Filings** | Finance Manager files VAT, PAYE, WHT (monthly by 15th). Corporate income tax return (within 6 months of FY-end). Provisional tax (quarterly) |
| **URSB** | Legal/Compliance Officer files annual returns (within 42 days of AGM or anniversary of incorporation). Notify changes in directors/shareholders within 28 days |
| **NSSF** | Finance Manager remits employer (10%) and employee (5%) contributions by 15th of following month |
| **Trading Licence** | Legal/Compliance Officer renews annually with KCCA/local government (typically January) |
| **Sector Permits** | Department Head coordinates with Legal/Compliance Officer for sector-specific renewals |
| **Insurance** | Finance Manager reviews and renews all insurance policies before expiry |
| **PDPO** | Legal/Compliance Officer ensures registration and annual renewal with Personal Data Protection Office |

### Step 5: Collect and File Evidence

| Detail | Description |
|--------|-------------|
| **Action** | Collect proof of compliance for each obligation fulfilled |
| **Who** | Legal/Compliance Officer (coordinate); responsible person (provide) |
| **Evidence Types** | Filing receipts, tax clearance certificates, licence certificates, payment receipts, registration confirmations, acknowledgment letters |
| **Storage** | Physical: compliance evidence file (by year). Digital: compliance folder in shared drive / ERP |
| **Retention** | Minimum 7 years (10 years for tax-related evidence per Income Tax Act) |

### Step 6: Quarterly Compliance Review

| Detail | Description |
|--------|-------------|
| **Action** | Review compliance status across all obligations |
| **Who** | Legal/Compliance Officer (prepare); MD (review and approve) |
| **Frequency** | Quarterly (aligned with Board meeting schedule) |
| **Review Includes** | Status of all obligations (green/amber/red), upcoming deadlines for next quarter, any non-compliance incidents and remediation, regulatory changes affecting the company, new obligations identified |
| **Output** | Quarterly Compliance Status Report |
| **Distribution** | MD, Finance Manager, Board (summary) |

### Step 7: Annual Compliance Report

| Detail | Description |
|--------|-------------|
| **Action** | Prepare comprehensive annual compliance report for the Board |
| **Who** | Legal/Compliance Officer |
| **Frequency** | Annually (Q1 of following year, aligned with annual audit) |
| **Content** | Summary of all compliance obligations and status, non-compliance incidents and outcomes, penalties or fines incurred, regulatory changes during the year, compliance improvement recommendations, compliance plan for the coming year |
| **Approval** | MD reviews; Board notes/approves |

### Step 8: Remediate Non-Compliance

| Detail | Description |
|--------|-------------|
| **Action** | When non-compliance is identified, take immediate corrective action |
| **Who** | Legal/Compliance Officer (coordinate); responsible person (execute) |
| **Process** | Identify root cause, determine remediation actions, assign responsibilities and deadlines, implement corrective measures, file late submissions with penalties if applicable, document lessons learned |
| **Reporting** | All non-compliance incidents reported to MD immediately. Material non-compliance reported to Board |
| **Follow-Up** | Verify remediation within 30 days |

## 6. Controls and Approvals

| Control | Description |
|---------|-------------|
| **Single Point of Accountability** | Legal/Compliance Officer is the central coordinator for all compliance obligations |
| **Dual Monitoring** | Finance Manager independently monitors tax deadlines; HR monitors employment obligations |

| **Evidence Requirement** | No obligation marked "complete" without supporting evidence filed |
| **Quarterly Sign-Off** | MD signs off on quarterly compliance status report |

## 9. Lean vs Controlled Version

### Lean Version (Small Team < 15 people)

| Aspect | Lean Approach |
|--------|---------------|
| **Compliance Register** | Google Sheet / Excel with colour-coded status (green/amber/red) |
| **Monitoring** | Google Calendar alerts set by HR & Admin Officer |
| **Tax Filings** | External accountant files URA returns; Finance Manager oversees |
| **URSB Filings** | HR & Admin Officer coordinates with external company secretary |
| **Trading Licence** | HR & Admin Officer handles renewal with MD approval |
| **Quarterly Review** | MD reviews spreadsheet monthly; discusses at management meeting quarterly |
| **Annual Report** | Simple summary memo prepared by HR & Admin Officer for MD |
| **Evidence Storage** | Physical file + scanned copies in Google Drive |
| **Responsible Person** | HR & Admin Officer (primary) with Finance Manager support |
| **External Support** | External accountant for tax; external lawyer for regulatory queries |

### Controlled Version (Mid-size Team 15-100+ people)

| Aspect | Controlled Approach |
|--------|---------------------|
| **Compliance Register** | ERP compliance module with workflow automation |
| **Monitoring** | Automated multi-level alerts (90/60/30/7/0 days) |
| **Tax Filings** | Tax & Compliance Officer files all URA returns; CFO oversees |
| **URSB Filings** | Legal/Compliance Officer manages directly |
| **Trading Licence** | Legal/Compliance Officer manages with sector department heads |
| **Quarterly Review** | Formal quarterly compliance committee meeting (Legal, Finance, HR, MD) |
| **Annual Report** | Comprehensive compliance report with risk assessment to Board |
| **Evidence Storage** | ERP document management with audit trail |
| **Responsible Person** | Legal/Compliance Officer (dedicated) |
| **External Support** | External law firm on retainer; Big 4 / mid-tier tax advisors |
