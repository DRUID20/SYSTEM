## 1. Purpose

This SOP defines the standard process for managing the sales pipeline from initial lead capture through deal closure (won or lost). It ensures consistent lead handling, accurate forecasting, data integrity in the CRM, and accountability for pipeline progression across all business lines of Awdeer Investments Limited.

## 5. Step-by-Step Workflow

### Step 1: Lead Capture

| Detail | Description |
|--------|------------|
| **Action** | Receive enquiry and create a new lead record in CRM |
| **Who** | Sales Executive (or any staff who receives the enquiry) |
| **How** | Enter all required fields: Company Name, Contact Name, Phone/Email, Lead Source, Business Line, Estimated Value (if known), Assigned To |
| **Tool** | CRM system or Lead Tracking Sheet (SAL-TPL-001) |
| **SLA** | Same business day as enquiry received |
| **Notes** | If a non-sales staff member receives the enquiry, they forward details to Sales Executive within 2 hours |

### Step 2: Lead Assignment

| Detail | Description |
|--------|------------|
| **Action** | Sales Manager assigns the lead to the appropriate Sales Executive based on business line, geography, or workload |
| **Who** | Sales Manager |
| **How** | Update the Assigned To field in CRM; notify the Sales Executive |
| **SLA** | Same business day |
| **Lean version** | Sales Lead self-assigns (only one person); MD is notified |

### Step 3: Initial Contact

| Detail | Description |
|--------|------------|
| **Action** | Sales Executive makes initial contact with the prospect |
| **Who** | Sales Executive |
| **How** | Phone call, email, or in-person visit. Objective: introduce Awdeer, understand the customer's need at a high level, confirm interest |
| **SLA** | Within 1 business day of assignment |
| **Notes** | Log the contact attempt and outcome in CRM (call notes, email sent, meeting scheduled) |

### Step 4: Lead Qualification (BANT)

| Detail | Description |
|--------|------------|
| **Action** | Qualify the lead using the BANT framework |
| **Who** | Sales Executive |
| **How** | Through conversation with the prospect, assess: |
| | **B — Budget**: Does the customer have budget allocated? What is their price expectation? |
| | **A — Authority**: Is the contact the decision-maker? If not, who is? |
| | **N — Need**: Is there a genuine, specific need that Awdeer can fulfil? |
| | **T — Timeline**: When does the customer need the solution delivered? |
| **Decision** | If at least 3 of 4 BANT criteria are positive: move to Qualified. If fewer: keep as Lead with nurture plan or disqualify |
| **SLA** | Complete within 3 business days of initial contact |
| **Output** | CRM updated: stage changed to Qualified (or Lead with notes explaining nurture/disqualify decision) |

### Step 5: Advance to Proposal Stage

| Detail | Description |
|--------|------------|
| **Action** | When a qualified lead requests or agrees to receive a formal proposal/quotation, move to Proposal stage |
| **Who** | Sales Executive |
| **How** | Update CRM stage to Proposal; initiate quotation preparation per SAL-QTC-001 |
| **SLA** | Stage update same day as customer confirms interest in proposal |

### Step 6: Advance to Negotiation Stage

| Detail | Description |
|--------|------------|
| **Action** | When the customer provides feedback on the proposal and enters pricing/terms discussion, move to Negotiation |
| **Who** | Sales Executive |
| **How** | Update CRM stage to Negotiation; log customer feedback and objections |
| **SLA** | Stage update same day as negotiation begins |
| **Notes** | If revised quotation is needed, follow SAL-QTC-001 |

### Step 7: Close — Won

| Detail | Description |
|--------|------------|
| **Action** | Customer accepts proposal, signs contract or issues PO |
| **Who** | Sales Executive |
| **How** | Update CRM stage to Won; record actual deal value, close date; initiate order per SAL-ORD-001 |
| **SLA** | CRM update same day as deal closure |
| **Notes** | Sales Manager notified; deal included in monthly reporting |

### Step 8: Close — Lost

| Detail | Description |
|--------|------------|
| **Action** | Customer declines proposal or goes silent beyond follow-up window |
| **Who** | Sales Executive |
| **How** | Update CRM stage to Lost; record Loss Reason (Price, Competitor, Timing, No Budget, No Response, Other) |
| **SLA** | Mark as Lost if no response after 3 follow-up attempts over 21 days (or if customer explicitly declines) |
| **Notes** | Sales Manager reviews all lost deals in monthly pipeline meeting |

### Step 9: Pipeline Review Meeting

| Detail | Description |
|--------|------------|
| **Action** | Conduct regular pipeline review to assess health, velocity, and forecast |
| **Who** | Sales Manager (facilitates), Sales Executives (report), MD (informed) |
| **Agenda** | 1. New leads this period 2. Stage changes 3. Stalled deals (no activity > 14 days) 4. Deals expected to close this month 5. Forecast vs target 6. Actions and owners |
| **Frequency** | Weekly (Controlled) / Weekly informal check-in (Lean) |
| **Output** | Updated pipeline, action items, forecast |

### Step 10: Reporting

| Detail | Description |
|--------|------------|
| **Action** | Generate pipeline and sales performance reports |
| **Who** | Sales Manager |
| **Frequency** | Weekly pipeline report to MD; Monthly dashboard |
| **Content** | See KPI section below |

## 6. Controls & Approvals

| Control Point | Control Description | Responsible |
|--------------|-------------------|-------------|
| Lead logging completeness | All enquiries must be logged in CRM within same business day | Sales Manager verifies daily |
| Required field validation | CRM enforces mandatory fields: Company, Contact, Source, Business Line, Owner | CRM system / Sales Manager |
| Stage progression rules | Stages can only move forward (or to Lost); backward movement requires Sales Manager approval with documented reason | CRM configuration / Sales Manager |
| Stalled deal alerts | Opportunities with no activity for > 14 days are flagged automatically | CRM automation / Sales Manager |
| Win/loss reason mandatory | CRM requires loss reason before closing as Lost; requires actual value before closing as Won | CRM configuration |
| Data quality audit | Monthly review of CRM data for completeness, accuracy, and duplicates | Sales Manager |
| Segregation | Sales Executive cannot approve own discount requests (handled via SAL-QTC-001) | Sales Manager / MD |
| Forecast accuracy | Compare prior month's forecast to actual results; variance > 20% triggers review | Sales Manager |

## 8. KPIs

| KPI | Definition | Target | Measurement Frequency |
|-----|-----------|--------|----------------------|
| Lead Response Time | Time from enquiry receipt to first contact | < 1 business day | Weekly |
| Lead-to-Qualified Conversion | % of leads that reach Qualified stage | > 40% | Monthly |
| Qualified-to-Won Conversion | % of Qualified leads that reach Won | > 30% | Monthly |
| Overall Conversion Rate | Won / Total Leads | > 20% | Monthly |
| Average Sales Cycle | Days from Lead creation to Won | < 45 days | Monthly |
| Pipeline Velocity | (Number of deals x Average deal value x Win rate) / Average cycle length | Increasing trend | Monthly |
| Pipeline Coverage Ratio | Total pipeline value / Revenue target | > 3x quarter target | Weekly |
| Stalled Deal Ratio | Deals with no activity > 14 days / Total active deals | < 15% | Weekly |
| CRM Data Completeness | % of records with all required fields filled | > 95% | Monthly |
| Forecast Accuracy | Actual revenue / Forecasted revenue | Within +/- 20% | Monthly |

## 9. Lean Version — Summary

| Element | Lean Approach |
|---------|--------------|
| CRM tool | Google Sheets / Excel using SAL-TPL-001 or free CRM (HubSpot Free) |
| Lead assignment | Sales Lead self-assigns; MD is copied |
| Qualification | Conversational BANT; documented in notes field |
| Pipeline review | Weekly 15-minute standup with MD (in-person or phone) |
| Reporting | Weekly email summary from Sales Lead to MD |
| Data quality | Sales Lead self-checks; MD spot-checks monthly |
| Stalled deals | Sales Lead reviews own pipeline weekly; MD prompts action |
| Forecasting | Sales Lead provides top-line estimate to MD monthly |

---

## 10. Controlled Version — Summary

| Element | Controlled Approach |
|---------|-------------------|
| CRM tool | Full CRM module in ERP (Odoo CRM or equivalent) |
| Lead assignment | Sales Manager assigns based on rules (business line, territory, workload) |
| Qualification | Formal BANT checklist completed in CRM with scoring |
| Pipeline review | Weekly 30-minute structured meeting with agenda |
| Reporting | Automated weekly and monthly reports from CRM |
| Data quality | Monthly CRM hygiene audit; Sales Manager accountable |
| Stalled deals | Automated alerts at 14 days; Sales Manager follows up |
| Forecasting | Bottom-up forecast from each Sales Executive; Sales Manager consolidates; accuracy tracked |
| Automation | Auto-reminders for next actions, stage aging alerts, email templates for follow-up |
| Analytics | Win/loss analysis by business line, source, sales person; trend reporting |
