## 1. Purpose

To define the standard operating procedure for managing contracts throughout their full lifecycle — from initial request through drafting, review, approval, execution, storage, monitoring, and renewal or termination — ensuring that all contractual commitments are properly authorised, legally sound, and tracked.

---

## 2. Scope

This SOP applies to all contracts entered into by Awdeer Investments Limited, including:

- Commercial agreements (customer and supplier)
- Employment and consultancy contracts
- Property and lease agreements
- Loan and financial facility agreements
- Technology and software licence agreements
- Non-disclosure and confidentiality agreements
- Joint venture and partnership agreements
- Government and regulatory submissions requiring contractual commitment

**Exclusions:** Routine purchase orders below UGX 2,000,000 processed through the procurement system (see PRO-PUR-001).

## 5. Step-by-Step Workflow

### Step 1: Contract Request

| Detail | Description |
|--------|-------------|
| **Action** | The requesting party identifies a need for a contractual arrangement and submits a Contract Request Form |
| **Who** | Requestor (any staff member) |
| **How** | Complete contract request form specifying: parties, purpose, estimated value, timeline, key terms |
| **Approval** | Department Head approves the request before it proceeds to Legal |
| **Timeline** | Within 1 business day of need identification |
| **System** | ERP workflow / email with form attachment |

### Step 2: Drafting / Receipt of Contract

| Detail | Description |
|--------|-------------|
| **Action** | Legal/Compliance Officer either drafts the contract or receives the counterparty's draft for review |
| **Who** | Legal/Compliance Officer |
| **How** | Use company standard templates where available. For non-standard or high-value contracts, engage external legal counsel |
| **Considerations** | Always prefer Awdeer's own templates. If using counterparty's template, apply full review checklist (LEG-TPL-001) |
| **Timeline** | Within 3 business days (standard); within 5 business days (complex) |

### Step 3: Legal Review

| Detail | Description |
|--------|-------------|
| **Action** | Comprehensive legal review of all contract terms using the Contract Review Checklist |
| **Who** | Legal/Compliance Officer (internal); External counsel (for high-value/complex contracts) |
| **How** | Complete LEG-TPL-001 Contract Review Checklist. Flag risks, non-standard clauses, and compliance issues |
| **External Counsel Threshold** | Contracts above UGX 100,000,000 or involving property, loans, or regulatory matters |
| **Timeline** | Within 3 business days (standard); within 5 business days (with external counsel) |

### Step 4: Financial Review

| Detail | Description |
|--------|-------------|
| **Action** | Finance Manager reviews financial terms, tax implications, and budget impact |
| **Who** | Finance Manager |
| **How** | Verify: pricing accuracy, payment terms feasibility, WHT/VAT implications, budget availability, forex exposure (if applicable) |
| **Timeline** | Within 2 business days |

### Step 5: Negotiation

| Detail | Description |
|--------|-------------|
| **Action** | Negotiate amendments to unacceptable or high-risk terms with the counterparty |
| **Who** | Legal/Compliance Officer (lead) with input from requestor and Finance |
| **How** | Track all changes using redline / tracked changes. Document negotiation positions and rationale |
| **Escalation** | If counterparty will not accept critical amendments, escalate to MD for strategic decision |
| **Timeline** | Variable; target completion within 10 business days |

### Step 6: Approval

| Detail | Description |
|--------|-------------|
| **Action** | Obtain approval from the appropriate authority per the Signing Authority Matrix |
| **Who** | Per Signing Authority Matrix (see main document Section 4.4) |
| **How** | Present final contract with: completed review checklist, financial review memo, risk summary, recommendation |
| **Documentation** | Approval recorded in ERP / email trail / approval form |
| **Timeline** | Within 2 business days of submission |

### Step 7: Execution / Signing

| Detail | Description |
|--------|-------------|
| **Action** | Authorised signatory executes the contract |
| **Who** | As per Signing Authority Matrix |
| **How** | Two original copies signed by both parties (or electronic signature per Electronic Transactions Act 2011). Company seal affixed where required |
| **Witnessing** | Contracts above UGX 100,000,000 should be witnessed. Property contracts require witness signatures |
| **Timeline** | Within 2 business days of approval |
| **Post-Execution** | Legal/Compliance Officer confirms execution and distributes copies |

### Step 8: Storage and Registration

| Detail | Description |
|--------|-------------|
| **Action** | Store executed contract securely and register in the contract management system |
| **Who** | Legal/Compliance Officer |
| **How** | Physical: locked filing cabinet with restricted access. Digital: ERP contract module or secure shared drive with access controls |
| **Registration** | Enter into Contract Register: parties, type, value, start date, end date, key obligations, renewal date, responsible person |
| **Additional** | Register with relevant authority if required (e.g., stamp duty at URA, land titles at Ministry of Lands) |
| **Timeline** | Within 2 business days of execution |

### Step 9: Obligation Monitoring

| Detail | Description |
|--------|-------------|
| **Action** | Ongoing monitoring of contractual obligations, milestones, and compliance |
| **Who** | Legal/Compliance Officer + responsible department |
| **How** | Monthly review of active contracts. Track: payment schedules, delivery milestones, reporting obligations, compliance requirements |
| **Alerts** | Set automated alerts for: payment due dates, milestone dates, reporting deadlines, insurance renewal requirements |
| **Escalation** | Notify MD immediately if counterparty breach is identified or if company is at risk of non-performance |

### Step 10: Renewal or Termination

| Detail | Description |
|--------|-------------|
| **Action** | Review contract 60 days before expiry and decide on renewal, renegotiation, or termination |
| **Who** | Legal/Compliance Officer (initiate review); responsible department (provide input); MD (approve decision) |
| **60-Day Alert** | System generates alert to Legal/Compliance Officer and responsible department head |
| **Decision** | Renew (same terms), renegotiate (amended terms), or terminate (serve notice per contract terms) |
| **Documentation** | Record decision and rationale. If renewing/renegotiating, restart process from Step 2 |
| **Timeline** | Decision made at least 30 days before expiry to allow for notice period |

## 6. Controls and Approvals

| Control | Description |
|---------|-------------|
| **Segregation of Duties** | Requestor cannot approve their own contract. Reviewer cannot be the sole signatory |
| **Signing Authority** | No contract executed without proper authority per the Signing Authority Matrix |
| **Legal Review Mandatory** | All contracts above UGX 5,000,000 must receive legal review |
| **Financial Review** | All contracts with financial commitments require Finance Manager sign-off |
| **External Counsel** | Mandatory for contracts above UGX 100,000,000, all property/loan contracts |
| **Board Approval** | Required for contracts above UGX 500,000,000, all property and loan contracts |
| **Stamp Duty** | Verify stamp duty requirements (per Stamps Act) and ensure payment before execution |
| **KYC Clearance** | No contract with a new counterparty without completed KYC (per LEG-AML-001) |
| **Audit Trail** | Complete record of request, review, approval, negotiation, and execution maintained |

## 9. Lean vs Controlled Version

### Lean Version (Small Team < 15 people)

| Aspect | Lean Approach |
|--------|---------------|
| **Contract Request** | Verbal or email request to MD with brief justification |
| **Drafting** | Use standard templates. MD drafts simple contracts. External lawyer for complex ones |
| **Legal Review** | MD reviews simple contracts using checklist. External lawyer for contracts above UGX 20,000,000 |
| **Financial Review** | Finance Manager / Accountant confirms budget and tax implications |
| **Approval** | MD approves all contracts (Board Chair for property/loan) |
| **Execution** | MD signs. HR & Admin Officer witnesses |
| **Storage** | Locked cabinet + scanned copies in secure shared folder |
| **Monitoring** | Spreadsheet-based contract register with calendar alerts for expiry dates |
| **Renewal** | HR & Admin Officer alerts MD 60 days before expiry |
| **Tools** | Google Sheets / Excel contract register, Google Drive / physical filing |

### Controlled Version (Mid-size Team 15-100+ people)

| Aspect | Controlled Approach |
|--------|---------------------|
| **Contract Request** | Formal request form in ERP with workflow routing |
| **Drafting** | Legal/Compliance Officer drafts or reviews. External law firm on retainer |
| **Legal Review** | Legal/Compliance Officer completes full review checklist. External counsel for high-value/complex |
| **Financial Review** | Finance Manager formal review with written sign-off |
| **Approval** | Multi-level approval per Signing Authority Matrix in ERP workflow |
| **Execution** | Authorised signatory per DoA. Electronic signature where permitted |
| **Storage** | ERP contract module with version control, access restrictions, and audit trail |
| **Monitoring** | Automated obligation tracking with alerts. Monthly review meetings |
| **Renewal** | System-generated 90/60/30-day alerts. Formal renewal review process |
| **Tools** | ERP contract management module, document management system |
